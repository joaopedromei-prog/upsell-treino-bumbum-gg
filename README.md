# Upsell Treino Bumbum GG — Musa Elite

Página de upsell em formato TSL exibida após a compra do **Treino Bumbum GG**, oferecendo o **Acompanhamento Musa Elite**.

## Conteúdo

- `upsell-treino-bumbum-gg.html`: página principal.
- `upsell tsl musa elite controle_files/`: estilos, scripts e imagens necessários para a página.

## Visualização local

Abra `upsell-treino-bumbum-gg.html` no navegador mantendo a pasta de arquivos no mesmo diretório.

## Publicação

Antes de colocar a página em produção, confirme os identificadores do checkout Payt, as URLs de downsell e os parâmetros de rastreamento usados no funil.
